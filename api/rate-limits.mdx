---
title: "Rate limits"
description: "How many requests you can send to the Fincra API."
keywords: ["rate limits", "requests per second", "throttling"]
---

Fincra limits how many requests you can send, so the API stays fast and reliable for everyone.

| Window | Limit |
|---|---|
| Per second | 100 requests |
| Per minute | 4,200 requests |
| Per hour | 200,000 requests |

If you send many requests at once, spread them out. For example, send payouts in steady batches rather than all in the same second.
