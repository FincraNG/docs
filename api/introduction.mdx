  <div>
    <p>The Fincra API is a REST API. You send requests over HTTPS to the base URL for your environment, with your secret key in a header and any data in JSON. Fincra replies in JSON, telling you whether the request was successful and returning the result.</p>
    <p>Use sandbox to build and test your integration safely. Transactions in sandbox are simulated, so they don't affect real accounts or balances.</p>
    <p>When your integration works end to end in sandbox, replace your sandbox key and base URL with your production key and base URL. Production needs your business onboarding completed first.</p>
  </div>
  <div className="base-url-table">
    | Base URL | Environment |
    |---|---|
    | `https://sandboxapi.fincra.com` | Sandbox |
    | `https://api.fincra.com` | Production |
