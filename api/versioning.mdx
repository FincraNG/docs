---
title: "Versioning"
description: "How Fincra changes the API without breaking your integration."
keywords: ["versioning", "breaking changes", "deprecation", "changelog"]
---

The Fincra API has one version, so you don't need to set a version in your requests.

Fincra adds new endpoints, optional fields and new values without notice. Build your integration to ignore fields and values it doesn't recognise.
