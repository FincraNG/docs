The Fincra API is a REST API. You send requests over HTTPS to the base URL for your environment, with your secret key in a header and any data in JSON. Fincra replies in JSON, telling you whether the request was successful and returning the result.

Start in sandbox. It works like production but moves no real money. When your integration works, switch to your production key and base URL.

<Panel>
  ```text Base URLs
  Sandbox
  https://sandboxapi.fincra.com

  Production
  https://api.fincra.com
  ```

  ```bash Authenticated request
  curl https://sandboxapi.fincra.com/profile/business/me \
    -H "api-key: {{SECRET_KEY}}"
  ```
</Panel>

## Environments

| Environment | Base URL | Use it to |
|---|---|---|
| Sandbox | `https://sandboxapi.fincra.com` | Build and test your integration |
| Production | `https://api.fincra.com` | Move real money |

Each environment has its own secret key. Use your sandbox key with the sandbox base URL and your production key with the production base URL.

## Authentication

Send your secret key in the `api-key` header of every request. You generate the key in the dashboard under **My Account** > **API Keys & Webhooks**. [Create a sandbox account](/quickstart/create-a-sandbox-account#generate-your-api-keys) shows the steps.

Keep your secret key on your server. Anyone with it can make requests as your business.
