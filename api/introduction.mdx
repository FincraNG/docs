The Fincra API is a REST API. You send requests over HTTPS to the base URL for your environment, with your secret key in a header and any data in JSON. Fincra replies in JSON, telling you whether the request was successful and returning the result.

Start in sandbox. It works like production but moves no real money. When your integration works, switch to your production key and base URL.

<Panel>
  ```text Base URLs
  Sandbox
  https://sandboxapi.fincra.com

  Production
  https://api.fincra.com
  ```

  ```bash Authenticated request
  curl https://sandboxapi.fincra.com/profile/business/me \
    -H "api-key: {{SECRET_KEY}}"
  ```
</Panel>
